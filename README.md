# Noise Cancellation and LSB Steganography

## Overview

This project explores two audio signal-processing topics: **noise cancellation** and **Least Significant Bit (LSB) steganography**. The Jupyter notebook analyzes a recorded voice signal, adds simulated 50 Hz power-line interference, and compares adaptive LMS filtering with FIR and IIR filters. It also examines an audio file containing an LSB-encoded message, detects added tonal interference using the FFT, and tests frequency-domain noise removal to recover the message.

## Results

### Noise cancellation

A 50 Hz sinusoid was added to the recorded voice signal. The notebook reports the following comparison:

| Method | Output SNR (dB) | Noise reduction (dB) |
|---|---:|---:|
| Noisy signal (baseline) | -10.50 | 0.00 |
| FIR filter | -11.23 | -0.73 |
| IIR notch filter | 9.76 | 20.26 |
| Adaptive LMS filter | **33.91** | **44.41** |

For this experiment, the **adaptive LMS filter performed best**, followed by the IIR notch filter. The tested FIR design did not remove the interference effectively and slightly degraded the measured result.

### LSB steganography

The decoder successfully recovered **`Signals & System`** from the clean audio file `100-2625.wav`. For the noisy file, FFT analysis identified interference peaks near **1500.06 Hz** and **2500.05 Hz**. Replacing narrow bands around those frequencies through spectral interpolation produced a partially corrupted message (`Oignals & Syste…`), while the tested IIR-notch and adaptive-LMS approaches did not recover the hidden text correctly. This shows that ordinary noise reduction does not necessarily preserve the sample-level bit patterns required by LSB decoding.
